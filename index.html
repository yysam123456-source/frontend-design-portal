Frontend Design Gallery — open-source UI components and animations

What Frontend Design Gallery indexes

The gallery is a browsable index of open-source UI components, animations and effects, assembled from fourteen upstream projects rather than written in-house. The published dataset holds 6,425 entries, and each one carries a description, a technology list and a copyable code snippet. Previews render in the page itself instead of linking out.

  • 3,802 entries come from Uiverse, 417 from Anime.js, 269 from React Bits, 244 from PixelFX, 240 from ASCII.Art and 123 from Looseleaf.
  • The other eight sources are Animata, Eldora UI, ThreeUI, Zelda Hyrule UI, Pixel2Motion, PixiJS, ASCII.Art and Ascii Sharks.
  • Ninety-three category labels sort the collection, led by 1,231 buttons, 726 cards and 718 loaders.
  • Filters combine category with technology stack, so React animations can be isolated from CSS snippets.

How the previews work

Every entry has a preview record, and most of them execute rather than illustrate: 4,312 render as live HTML, 572 render compiled React and 123 open the Looseleaf official demo in an isolated iframe. Those HTML previews run in an iframe that receives its markup through srcDoc, so demo styles and markup stay inside their own document.

  • The preview manifest covers all 5,451 entries; 5,423 are marked ready and 28 are flagged unsupported.
  • The remaining 416 previews are recorded media, 268 video and 148 image, captured from the upstream demo.
  • A copy button beside each snippet writes the raw source to the clipboard in one click.
  • Snippets are fetched from the upstream repositories when the dataset is built, so they match the code those projects ship.

What it does not do

The gallery is an index, not a package. Nothing installs, and no component is authored here: the code comes from upstream repositories, whose licences apply rather than this site's.

  • Twenty-eight entries are flagged unsupported and have no working preview.
  • Recorded demos show behaviour rather than execute it, so editing the code is the only way to test changes.
  • Code copied from Uiverse, React Bits or Anime.js keeps that project's licence, not one site-wide licence.
