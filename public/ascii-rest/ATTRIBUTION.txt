The runtime in this folder is a self-hosted copy of the files published at
https://ascii.rest, so the portal does not depend on ascii.rest's CDN:

  ascii-art.js   the <ascii-art> custom element used by the portal. Trimmed
                 from upstream ascii.js: only <ascii-art> is defined (the
                 <ascii-banner> element is omitted), and the @font-face
                 source points at the local file below.
  ascii.js       upstream element source (font URL rewritten to local).
  library.js     piece-name -> module map and loader.
  mount.js       renderer (canvas for palette pieces, <pre> for text pieces).
  banner.js      upstream <ascii-banner> renderer (kept for reference).
  pieces/*.js    240 piece modules, each with `export const meta` and a
                 default frame function.
  fonts/ascii-rest-mono.woff2
                 JetBrains Mono subset (3 KB) used for the box-drawing
                 glyphs in text pieces. JetBrains Mono is licensed under the
                 SIL Open Font License 1.1.

Upstream credits carried by the project README:
  - Logo, distribution and company marks are drawn from Devicon (MIT)
    and Simple Icons (CC0 1.0).
  - The piece format follows the classic ASCII animation tradition
    (donut.c and its descendants); individual pieces note their reference
    in the `note` field.
